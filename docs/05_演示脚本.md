# 121 秒产品演示｜字幕版

提交包根目录已包含 `EventLens_120秒产品演示.mp4`：H.264/AAC，1920×1080，实测约 120.96 秒。视频使用真实网页交互后的状态截图进行剪辑，加说明字幕和静音音轨；它不是连续原始录屏，也没有真人或合成口播。场景按正常结果→证据→四种异常→人工跟踪→合规拦截→缺证自定义事件展示，且明确标注构造数据、非实时和未接入模型。

下表同时保留可复录的口播/连续录屏脚本；若需要替换为候选人本人讲解的视频，可照此操作。视频的实际生成方法见 `tools/build_demo_video.py`，截图取自本地运行的同一份 `dist/` 产品。

建议直接录屏 Web 产品，屏幕分辨率 1440×900 左右。口播自然即可，不需要讲 PPT。所有“数据”“公司”“行情”均要口头说明为构造样例。

## 录制前检查

1. 使用隐身窗口或清理本产品的本地跟踪状态，以免“已确认”影响演示。
2. 浏览器打开已发布 URL 或本地预览 URL，先确认首屏显示“构造数据 · 非实时”。
3. 站点虽配置为公开，但自动化匿名访问返回 403 防护页；须由候选人用普通未登录浏览器确认评委可打开，若同样被拦截应迁移到其他公开托管。
4. 不要把 API Key、个人简历、真实持仓或其他隐私放进录屏。

## 三个高概率追问的简答

**问：为什么不是搜索加摘要？** 因为任务跨公告、财务、行情与后续披露，存在失败、冲突、时效及人工确认。Agent 的价值来自可恢复任务和证据门禁，而不只是写一段摘要。

**问：当前真的调用 LLM 了吗？** 没有。本次可运行版本演示编排与信任机制；真实模型接口要在有密钥和数据授权后接入服务端。它是带清晰边界的 MVP，而不是假装在线的模型能力。

**问：如何证明价值？** 用封存事件资料做交叉实验，对照人工检索，先守住引用覆盖和重大事实错误门槛，再比较完成时间与用户采纳率。
