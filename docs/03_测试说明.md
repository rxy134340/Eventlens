## 4. 缺陷与处理记录

| 发现 | 根因 | 处理与复测 |
|---|---|---|
| 首屏 HTML 加载但结果不渲染 | 本地服务把 `.mjs` 以 `text/plain` 返回，浏览器拒绝加载模块 | 发布目录改用 `.js` 模块；本地刷新后出现完整任务结果 |
| 数值事实缺单位仍可能校验通过 | 证据必填字段未含 `unit` | 增加单位门禁和失败/通过回归测试 |
| 过期行情仍可能被当成当前反应 | 缺少过期场景状态 | 增加过期标志、部分完成状态与回归测试 |
| 普通流程中来源数字被改动仍可能发布旧值 | 仅检查公告中硬编码数字，未比对辅助字段 | 从公告与财务字段解析同口径区间，一致后生成结论；异常时降级 |
| 部分自然语言交易请求漏拦 | 合规关键词覆盖过窄 | 扩充确定性涨跌和即时交易表达，并补回归用例 |

## 5. 评审建议操作顺序

先看默认样例，再展开 `[E1]` 核对原字段；运行故障演练；输入自定义事件；最后确认一个跟踪项并导出纪要。重点核对“无来源时不生成事实”的边界。
