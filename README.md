# EventLens｜事件驱动投研工作台

同花顺 AIME 金融智能 Agent 产品经理笔试作品。一个可操作的 Web MVP，展示事件输入、证据链、影响假设、异常降级、任务轨迹及人工跟踪闭环。

源代码仓库：[rxy134340/Eventlens](https://github.com/rxy134340/Eventlens)。

在线演示：[EventLens Web 产品](https://eventlens-aime-2027.b2dxm9hj2b.chatgpt.site/)；站点设为公开，但自动化匿名访问遇到站点防护返回 403，因此请在普通浏览器中复核可访问性。若评委环境也被拦截，可在本地按下述方式启动 `dist/`。视频为提交包根目录的 `EventLens_120秒产品演示.mp4`，约 121 秒，字幕版、无口播。

## 30 秒体验

1. 打开产品，默认进入“星河材料业绩预告下修”构造样例。
2. 点击 `[E1] 查看原字段`，核对来源、发布时间、数据时点、单位与口径。
3. 依次点击“原文缺失”“数据冲突”“接口失败”“数据过期”，观察任务如何降级并暂停不可靠结论。
4. 回到“正常” → “跟踪清单” → “加入跟踪”，刷新页面，确认状态保留。
5. 修改事件文本并点击“运行研究任务”，观察自定义事件如何停在待证据/待核验状态。

## 本地运行

需要 Python 3 或任何可提供静态文件的 HTTP 服务：

```powershell
cd site
python -m http.server 8765 --directory dist
```

浏览器访问 `http://localhost:8765/`。直接双击 HTML 可能受浏览器 ES module 限制，建议使用本地服务。

运行行为测试需要 Node.js 20+，不需要下载依赖：

```powershell
cd site
npm test
```

## 产品选择

用户是需要在短时间内形成事件研究初稿的个人投资者/初级研究员。MVP 聚焦业绩预告下修事件，因为公告、预告区间、后续正式财报和市场反应都可形成可核查链条。产品把结论拆成事实、推断和未知，并把待核查项交给用户确认。详见 [产品设计说明](docs/01_产品设计说明.md)。

## AI 的角色与当前实现边界

目标架构中，LLM 负责从非结构化原文提取主体/数字/原因候选、生成有证据 ID 的假设和反证问题；Agent 负责规划查询、调用金融工具、保留状态与失败恢复。规则负责单位/期间/时效/引用校验及合规门禁。具体模型与工具接入契约见 [系统与数据接入规范](docs/06_系统与数据接入规范.md)。

**本版本实际运行的是本地确定性编排与构造数据**。没有调用 LLM、扶摇或 iFinD，也没有把浏览器里的用户输入发送到第三方服务。页面中的“AI Native”是目标产品机制和后续架构，不应被误解为已上线的实时 AI 投研服务。自定义事件缺少来源时只产生待核验状态，不生成市场事实。此取舍保证评审能完整操作状态与风险闭环，同时不捏造接口成功。

## 数据来源与安全

- 构造案例位于 `dist/fixtures.js`，公司名称和数值均为样例。`demo://` 标识内部样例 ID，不是外部链接。
- 题目提供的候选数据源为[扶摇金融数据文档](https://fuyao.aicubes.cn/docs/)及 [iFinD MCP](https://mcp.51ifind.com/?syncCookieTimes=1)。当前未验证具体工具名称或调用权限，正式接入以授权账户中的实际能力为准。
- 自定义材料只保存在当前页面内存；已确认跟踪项保存在浏览器 `localStorage`，不跨设备同步。导出纪要由浏览器本地生成。
- 代码库不含 API Key、真实持仓或个人隐私数据。若部署模型/金融接口，密钥应由服务端环境变量托管，严禁暴露在前端包中。

## 已知边界与未做事项

1. 尚未接入真实模型或授权金融数据，不能对真实公司给出自动事实分析。
2. 自定义材料未做原文抓取、链接可信度核验、OCR 或反事实检索。
3. 跟踪清单仅本地保存，不包含定时监控、推送和账户系统。
4. 故障演练由构造场景注入，非真实外部 API 故障。
5. 演示数字不能用于投资决策，结果不构成买卖建议。
