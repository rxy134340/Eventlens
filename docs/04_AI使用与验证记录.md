# AI 使用与验证记录

> 记录范围：本次笔试作品制作过程，截至 2026-10-01。此文件区分“AI 辅助完成的工作”“已独立验证的行为”“尚待候选人亲自复核的内容”，不虚构已接入的金融数据或模型调用。

## 1. 使用的 AI 工具与参与环节

| 工具 | 使用环节 | 产出 |
|---|---|---|
| Codex / 大模型对话 | 将开放题拆成目标用户、单一事件场景、MVP 主链路、数据/风险/评测框架 | 产品方案初稿和交付范围 |
| Codex / 代码辅助 | Web 页面、构造数据、任务状态机、证据校验、测试用例与文档 | 本仓库源文件 |
| 浏览器预览与本地测试 | 检查首屏、交互状态与兼容性 | 缺陷定位及修复记录 |
| Codex / 视频制作辅助 | 捕获真实网页交互状态、撰写说明字幕、剪辑并检查 MP4 时长与画面 | 约 121 秒字幕演示；不是连续原始录屏或候选人口播 |

本产品**运行时没有调用 LLM**；页面内“Agent”是结构化任务编排演示。AI 工具参与的是本作业的制作过程，不等于产品已具备线上模型能力。

## 2. 关键提示约束与人工判断

给 AI 的核心约束包括：明确目标用户与真实工作流；单场景可运行；事实/推断/不确定性分层；每个核心结论回到来源、时点、单位和口径；数据缺失/冲突/失败时不可静默给正常结论；不输出确定性涨跌预测、收益承诺或直接买卖建议；无凭据时只展示构造数据。

候选人在本轮对话中确认了“事件驱动投研 Copilot”的产品方向和执行基线。未记录候选人对最终成品逐项签字复核，因此提交前仍应亲自体验页面并核对本文的测试记录。

## 3. 发现并修正的问题

| 问题 | 证据 | 修正 |
|---|---|---|
| 页面首次加载无研究结果 | 本地服务对 `.mjs` 返回 `text/plain`；浏览器模块未执行 | 将发布模块改为 `.js`，刷新后检查首屏结果 |
| 引用校验遗漏单位 | 新增测试先出现 `true !== false` | 将 `unit` 纳入证据必填字段，测试转绿 |
| 过期行情未阻断当前反应 | 新增测试先出现 `reviewable` 而非 `partial` | 增加过期标记与降级分支，测试转绿 |
| 题目给出的数据源未能完成权限核验 | 数据文档网页访问失败/超时，且当前没有 API 凭据 | 不猜测具体接口名或假装实时接入；在 README 和页面写明边界 |
| 独立代码复核发现普通流程数值事实可能与 E2 不符 | 修改 E2 数值后仍发布旧硬编码结论 | 先新增失败用例，再将事实改为从双来源同口径字段生成，不一致时降级 |
| 独立代码复核发现部分自然语言请求漏拦 | “股价明天一定上涨”“现在买入这只股票”原先未进入阻断状态 | 先新增失败用例，再扩充合规判别表达 |

以上修正由 AI 辅助实施并通过工具复测；不能写成“候选人独立编码修复”。候选人如在后续修改中发现新问题，应追加真实记录。

## 4. 结果验证方法

1. 使用 Node 内置测试运行 14 项行为用例。
2. 在本地 HTTP 服务打开页面，检查首屏直接出现任务结果与来源标签。
3. 点击故障演练，核查部分完成、无事实卡、冲突并列与失败轨迹。
4. 对真实数据和模型接入保持“待验证”状态；没有调用日志就不宣称通过。
5. 使用 FFmpeg 检查演示 MP4 的编码、1920×1080 画面和约 120.96 秒时长，并抽帧检查字幕与产品界面。

## 5. 剩余风险与下一轮修正
